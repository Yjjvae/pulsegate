# v0.2.0 单线程 Asio 基线

## 环境

| 项目 | 值 |
| --- | --- |
| 操作系统 | Ubuntu 26.04 LTS（WSL2） |
| 内核 | Linux 6.18.33.2-microsoft-standard-WSL2 |
| 编译器 | GCC 15.2.0 |
| CMake | 4.2.3 |
| Boost | 1.90.0 |
| wrk | 4.1.0-4build3（临时解压运行） |
| 构建类型 | Release |
| I/O 模型 | 1 个 `io_context` 运行线程，C++20 Coroutine |

## 复现命令

在一个终端运行：

```bash
cmake --preset release
cmake --build --preset release
./build/release/app/pulsegate --listen 127.0.0.1:8080
```

在另一个终端运行：

```bash
wrk -t2 -c100 -d30s --latency http://127.0.0.1:8080/healthz
```

## 已知限制

- 不支持请求 `Transfer-Encoding: chunked`；
- 没有 Header、Body、Keep-Alive 的超时策略；
- 只有一个 I/O 线程，尚未做多线程吞吐扩展；
- Pipelining 按请求顺序处理和响应，不并行写入；
- 没有路由表、静态文件、反向代理、日志或指标系统。
